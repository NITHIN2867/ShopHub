## 🔍 USAGE TIPS

### When Downloading Images:
1. Search for product name on Unsplash
2. Download **largest size available**
3. **Rename to exact filename** from list
4. Save as **JPG** format
5. **Keep file size < 200KB** (use tinypng.com if needed)

### When Adding Products:
1. Go to Admin Dashboard
2. Add new product
3. Fill in product details
4. Set Image URL: `/images/[category]/[filename].jpg`
5. Example: `/images/electronics/wireless-headphones.jpg`
6. Click Save
