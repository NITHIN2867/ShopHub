## ⚡ Quick Download Tips

1. **Use Unsplash Search:**
   - Go to unsplash.com
   - Search for product name (e.g., "wireless headphones")
   - Download largest available size
   - Compress using TinyPNG.com

2. **Quick Compression:**
   - Upload to tinypng.com
   - Compress to ~100-150KB
   - Download compressed version

3. **File Naming:**
   - Always use exact filename from list
   - Use lowercase, no spaces
   - Use hyphens (-) not underscores (_)
