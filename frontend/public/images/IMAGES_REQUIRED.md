Create these folders in `frontend/public/images/`:

```

├── carousel/                 # Homepage carousel banners
├── electronics/              # Electronics category
├── fashion/                  # Fashion & Accessories
├── home-appliances/          # Kitchen & Home Appliances
├── home-decor/               # Home Decorations
└── home-furniture/           # Furniture
```

## Total Image Count: 45 images

**Image Specifications:**
- Format: JPG or PNG
- Resolution: Minimum 500x500px (Recommended: 600x600px or higher)
- File Size: Keep under 200KB per image for optimal performance
- Background: Preferably white or clean background for product shots
- Quality: Clear, high-quality product photographs

**Folder Path:** `d:\E-commerce web\frontend\public\images\`

Once you add the images, update the image mapping in:
`d:\E-commerce web\frontend\src\utils\imageMap.js`

To use local images instead of Unsplash URLs.
