## 🔄 HOW TO ADD PRODUCTS MANUALLY

1. **Login to Admin Dashboard**
   - Go to `/admin` if you're logged in as admin
   
2. **Add Product Form**
   - Fill in product name
   - Enter price and original price
   - Select category
   - Enter stock quantity
   - Add image URL: `/images/[category]/[filename]`
   - Set rating (1-5)
   - Add description
   - Click Save

3. **Example Product Entry:**
   ```
   Name: Premium Wireless Headphones
   Price: 4500
   Original Price: 7500
   Category: Electronics
   Image: /images/electronics/wireless-headphones.jpg
   Stock: 25
   Rating: 4.5
   Description: High-quality wireless headphones with noise cancellation...
   ```
